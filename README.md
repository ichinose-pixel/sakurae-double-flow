# サクラエ｜クリアサイクル・ピンパズル

サクラエの「メラニンの生成と蓄積をおさえる」という特徴をモチーフにしたゲーム体験型LPです。

## ゲーム
- 初期表示ではゲームのみ。最初のピンタップで30秒のゲームが始まります。3本のピンで流れをつなぎ、溜まった粒を減らします。
- 左上のシャッターで流入を減らし、右上の出口から排出。
- 右下のピンはU字の底の粒をせき止めています。抜くと出口へ流れます。
- 手数制限や誤選択による即失敗はありません。6通りの順序で操作できます。
- クリアまたは30秒経過で、短い「桜の襲」の転換 → スクロール式の商品説明 → ブランドストーリー → 体験セット。
- 「先に商品を見る」でゲームを省略可能。説明・追従CTAはゲーム終了／省略後のみ表示。再プレイで非表示に戻ります。
- dataLayerイベント: sakurae_game_start / game_clear / game_timeout / game_skip / product_view / cta_click（各イベントに sakurae_ 接頭辞）。
- 申込みボタンは商品LPへ移動します。

## GitHub Pages
Settings → Pages → Build and deployment を「Deploy from a branch」に設定し、`main` ブランチの `/ (root)` を選択して保存します。
ゲーム本体は `docs/` にあり、ルートの `index.html` から同じ素材を参照します。HTMLを更新した際は `npm run prepare:pages` でルートの入口も更新してください。

## 確認
`npm test`（Node.js）。依存パッケージのインストールは不要です。
6通りの操作順、各ピンを残した際の蓄積、途中からの回復、重複操作、再プレイ、画面転換を検証します。
ブラウザでは320×568・360×640・390×844・1440×900相当の表示で確認済み。実機のタッチ操作は未確認です。
