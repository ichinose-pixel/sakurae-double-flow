# サクラエ｜クリアサイクル・ピンパズル

サクラエの「メラニンの生成と蓄積をおさえる」という特徴をモチーフにしたPlayableバナーの試作です。

## ゲーム
- 自動開始。3本から2本のピンを選択。
- 左上のシャッターで流入を減らし、右上の出口から排出。
- 予備の粒を落とすと失敗。再挑戦できます。
- クリア後は「桜の襲」をイメージした転換 → 商品の図解 → 体験セットの案内。
- 申込みボタンは商品LPへ移動します。

## GitHub Pages
Settings → Pages → Build and deployment を「Deploy from a branch」に設定し、`main` ブランチの `/ (root)` を選択して保存します。
ゲーム本体は `docs/` にあり、ルートの `index.html` から同じ素材を参照します。HTMLを更新した際は `npm run prepare:pages` でルートの入口も更新してください。

## 確認
`npm test`（Node.js）。依存パッケージのインストールは不要です。
正解の操作順、誤選択、操作回数、再プレイ、画面転換を検証します。
ブラウザでは360×640・390×844相当の表示で確認済み。実機のタッチ操作は未確認です。
